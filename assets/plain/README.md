# Plain theme assets

Place the Plain theme artwork in this folder:

- `background.png` — full-screen green baize/table texture.
- `card.png` — standard card-face background texture.
- `back.png` — standard playing-card back pattern.

The Plain theme is intentionally hidden from the public theme selector. It is opened using the tiny, background-coloured shortcut at the bottom-left of the selector screen.

The theme currently inherits Deck Dungeon's gameplay mappings for monster, weapon, food, and portrait artwork; these can be replaced with generic card assets as needed.
